# hxyfront-62003 法医昆虫学样本记录

源提示词编号:5

法医昆虫学现场样本记录前端工具:记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式与鉴定备注。

## 功能

- **新建批次**:批次号、案件编号、采样地点、采样时间、暴露阶段、昆虫种类、发育阶段、保存方式、环境温度(作为首条温度记录)、鉴定备注(留空标记为待鉴定)
- **校验提示**:空表单/漏填逐项标红并弹出提示;批次号唯一,重复提交会被拦截并明确提示;提交期间防连点
- **批次列表**:按发育阶段(卵/幼虫/蛹/成虫)筛选,带计数;指标栏实时统计批次数、平均温度、阶段覆盖、待鉴定数
- **批次详情**:编辑全部字段并保存、移除批次(带确认);同一批次可追加多条温度记录,自动绘制 SVG 温度折线图(最低/最高/平均统计),支持删除单条记录
- **案件关联**:多个批次填写同一案件编号即归入同一案件;案件视图按编号分组展示阶段分布与待鉴定状态,可跳转回批次详情,详情中可改派案件
- **本地持久化**:全部数据保存在浏览器 localStorage,刷新不丢失;首次运行写入 3 条示例批次

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

```bash
npm run dev          # 先启动 dev server
node e2e-walkthrough.mjs
```
